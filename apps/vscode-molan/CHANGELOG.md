# Changelog

## Unreleased

## 0.1.10

- 介绍动画改为英文演示：阅读、调字号、流程图放大、表格编辑
- 插件顶栏最右改为设置齿轮，纸面放进设置；工作室设置可一键唤起 VS Code / Cursor 安装扩展

## 0.1.9

- 预览顶栏可调节字号、行距、段距、字距，选择记在本机

## 0.1.8

- 主页改为 https://molan.guoyoutech.cn/extension.html（含 Open VSX / VS Code 安装链接）

## 0.1.7

- 文档内查找：`Cmd/Ctrl+F` 打开查找栏，高亮匹配并跳转；VS Code 下也会接管工作区的查找快捷键

## 0.1.6

- 表格：窄表按内容收缩（不再右边留白底）；宽表限制在纸面宽度内并自动换行
- 宽表按每列内容的自然宽度分配空间；含长英文或行内代码的列保留更大的最小宽度
- 顶部「预览 / 复制原文」始终和标题同一行，窄窗口时标题省略，按钮不再掉到下面

## 0.1.4

- 工具条图标：用带 nonce 的脚本加载 SVG 精灵图，避免 webview CSP 拦掉 Vditor 的内联注入

## 0.1.3

- 打开 Markdown 默认进入编辑，不再先闪一下再切到预览
- 顶部格式工具条改为 flex 布局，避免被裁掉看不见
- 编辑与预览共用全宽纸面，避免切换时宽度跳动
- 宽表格在纸面最大宽度处自动换行；窄表格背景不再铺满整行

## 0.1.2

- 商店介绍改为面向普通用户
- 修正商店 README 截图地址（指向 `apps/vscode-molan/media/`）

## 0.1.1

- 打开 Markdown 默认进入预览，点「编辑」再改
- 只看不改时，关闭文件不再询问保存
- 安装包更小

## 0.1.0

- 首次发布：点击 Markdown 用墨览所见即所得打开
- 支持 `.md` / `.markdown` / `.mdown` / `.mdx`
- Mermaid 流程图观看（拖动 / 缩放）、源码编辑、复制代码或图片
- `Cmd/Ctrl+S` 写回原文件
