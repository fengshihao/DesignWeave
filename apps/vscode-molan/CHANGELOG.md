# Changelog

## 0.1.3

- 打开 Markdown 默认进入编辑，不再先闪一下再切到预览
- 顶部格式工具条改为 flex 布局，避免被裁掉看不见
- 编辑与预览共用全宽纸面，避免切换时宽度跳动
- 宽表格在纸面最大宽度处自动换行；窄表格背景不再铺满整行

## 0.1.2

- 商店介绍改为面向普通用户
- 修正商店 README 截图地址（指向 `apps/vscode-molan/media/`）

## 0.1.1

- 打开 Markdown 默认进入预览，点「编辑」再改
- 只看不改时，关闭文件不再询问保存
- 安装包更小

## 0.1.0

- 首次发布：点击 Markdown 用墨览所见即所得打开
- 支持 `.md` / `.markdown` / `.mdown` / `.mdx`
- Mermaid 流程图观看（拖动 / 缩放）、源码编辑、复制代码或图片
- `Cmd/Ctrl+S` 写回原文件
