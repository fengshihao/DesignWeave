# 墨览 · 本地 Markdown 工作室

**单文件**：打开 `index.html` 即可（Vditor 从 CDN 加载）。所见即所得编辑本地 Markdown；Chrome / Edge 可写回原文件。

样例文档：`sample.md`。

Chrome 用「选择文件夹」可写回；Cursor 内置浏览器请用「兼容模式选文件夹」。

## VS Code / Cursor 扩展

同一份 `index.html` 也是 VS Code 扩展的源：编译时抽出样式和编辑器脚本。点击 Markdown 即可打开，见 [`apps/vscode-molan/README.md`](../../apps/vscode-molan/README.md)。
