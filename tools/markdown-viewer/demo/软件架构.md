# 软件架构

打开即阅读。要点再点「编辑」。表格、公式、流程图都在纸面上渲染。

## 核心流程

```mermaid
flowchart LR
  A[用户下单] --> B[创建订单]
  B --> C{库存充足?}
  C -->|否| D[取消]
  C -->|是| E[预留库存]
  E --> F[已支付]
```

## 分层

| 层级 | 职责 | 技术栈 |
| --- | --- | --- |
| 展现 | 页面与交互 | Vue 3, TypeScript |
| 应用 | 用例编排 | Spring Boot |
| 领域 | 业务规则 | Java |
