## A. 安装与分发

- [x] **A0** 主场景  
  - 结论：_安装程序把本机跑成服务器；全员用浏览器。架构师 / 产品设计靠用户系统 + ACL_

- [x] **A1** 第一版安装形态  
  - 结论：_服务型安装包（内置 Node，开机可启动）。不做 Tauri/Electron 工作台_

- [x] **A2** Node 运行时  
  - 结论：_安装包内置 Node（或 Node SEA）。不换 Deno/Bun。用户不必预装 Node_

- [x] **A3** Docker 是否完全移出主文档，仅保留开发者附录？  
  - 结论：_是_

- [x] **A4** 网络绑定  
  - 结论：_可听本机或局域网；必须登录；管理接口靠 ACL 不是靠藏端口；不对公网裸奔_

## B. Claude 与工程

- [x] **B1** 文档默认落盘与存储形态  
  - 结论：_每个工程一个专有文档目录（Markdown 真相源）；代码仓全部默认只读；SQLite 仅索引/session/运行态（见 [04](./04-文档存储原则.md)、[07](./07-客户端架构.md)）_

- [x] **B2** 无代码仓能否创建工程？（纯概念 PRD）  
  - 结论：_允许只有文档根；持续提醒绑定代码根；可行性分析禁用_

- [x] **B3** MCP/skills 默认「全部复用」还是首次逐项确认？  
  - 结论：_默认全开（复用托管机 `~/.claude`）。架构师可在设置里关；产品设计不能改。无首次勾选向导_
