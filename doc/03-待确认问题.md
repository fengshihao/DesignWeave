## A. 安装与分发

- [x] **A0** 主场景  
  - 结论：_安装程序把本机跑成服务器；全员用浏览器。架构师 / 产品经理靠用户系统 + ACL_

- [x] **A1** 第一版安装形态  
  - 结论：_服务型安装包（内置 Node，开机可启动）。不做 Tauri/Electron 工作台_

- [x] **A2** Node 运行时  
  - 结论：_安装包内置 Node（或 Node SEA）。不换 Deno/Bun。用户不必预装 Node_

- [x] **A3** Docker 是否完全移出主文档，仅保留开发者附录？  
  - 结论：_是_

- [x] **A4** 网络绑定  
  - 结论：_可听本机或局域网；必须登录；管理接口靠 ACL；不对公网裸奔_
