## 文档打架处：听谁的、怎么做

### 1. 09 §3 第一刀 vs 11-4 P0

**决定：** 内部可日用听 11-4 P0，不听 09 旧六条。已回写 [09 §3](./09-云端迭代入口.md)。

P0 必须包含：登录 ACL、三栏工作台、墨览写回、导入保真、三档 AI、人 XOR AI、工程锁 / 预览、文档仓 Git、保存 ≠ 记入版本、只读跟随磁盘、信任条。  
仍不做：安装包打磨、邀请流、拆 SR、改业务代码、公网、实时协同、脏文档三选一。

### 2. 发送关卡：「保存一版」会不会把那句话发出去

**决定：** 不会。听 11-3，不听 11-2 / 11-4 旧文案「保存一版并开始」。

点发送不满足条件 → 消息留在输入框，弹出说明。提示里的「保存一版」只：把改动记入版本并退出编辑态。人再点一次发送。

### 3. 「已保存但未记入版本」算不算发送关卡

**决定：** 算。开 AI 前时间线上「我改之前」必须是干净的一刀。

两条提示分开，避免人以为字没落盘：

- 还在编辑 / 有未保存：先保存一版并退出编辑，再发给 AI。
- 已保存、未记入版本：先记入版本再发给 AI。（按钮仍叫「保存一版」）

两条都**不**自动发出刚才那句。

### 4. 07 的「留我的 / 用磁盘的」和 409

**决定：** 产品层不做脏文档三选一。人 XOR AI 之后，正常路径不会和 AI 抢同一篇。

写回协议仍用 `GET/PUT /v1/files` + `If-Match`（09 §2 已拍）。若旁路改了磁盘导致 409：人话「纸面和磁盘对不上，请重新打开这篇」，然后按只读跟上磁盘。不要「保留我的 / 用磁盘的 / 看差异」。

07 里 session「可暂停等人采纳文档」过时：AI 直接写盘；否决用「撤销这一版」。

### 5. 08 的采纳 / 拒绝卡片

**决定：** 第一版不做待采纳卡片。侧栏一轮结束给「对比上一版 / 撤销这一版」。磁盘在进行中就已经在写。

### 6. 06 F7 主区问答、产品经理自己选文件夹

**决定：** 过时。主区永远墨览。选文档根 / 代码根、新建工程，只有架构师。产品经理只打开已有工程。

### 7. 06 §8 把「局域网小服务器」写成不做

**决定：** 那句作废。听 00 / 07 / 09 §2：安装程序 + 本机服务器，可听本机或局域网，必须登录，不对公网裸奔。

### 8. 整仓回退、架构师解除编辑权的 P0 / P1

**决定：**

- 整仓回退：P0 不做实现，时间线菜单留位。
- 架构师「解除编辑权」：P0 要有按钮（对方留在工程里变成预览）。超时约 2 分钟按 11-3。边角文案打磨放 P1。

### 9. 界面怎么称呼

**决定：** 界面写「产品经理」。代码角色值仍用 `designer`（07 已拍），不要为了改名动 ACL 模型。

## 实现切片（听到「开始写代码」之后）

每一刀单独验收，不要一把梭。细节验收见审稿回复；这里只锁顺序：

1. **登录 ACL** — Better Auth + `architect` / `designer`；管理接口 403；共享口令退场  
2. **文件 + Git** — 1 文档根（必须版本库、主线）+ N 只读代码根；保存 ≠ 记入版本；AI 成功自动记一版  
3. **墨览宿主** — Web 接墨览；`GET/PUT /v1/files`；只读跟随；导入先保真  
4. **session 流** — POST 立刻返回；`GET .../stream?after=seq`；三档 AI；关浏览器 ≠ 取消  
5. **互斥与预览锁** — 发送关卡；人 XOR AI；一人编辑权，别人预览  

安装包打磨放这些刀之后。
