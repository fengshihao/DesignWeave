# DesignWeave 产品重定位

> 状态：已拍板 · 2026-08-15 · 2026-08-22 按 [18](./18-工程目录与标准PRD.md) 修订角色与工程模型 · 2026-09-02 托付交互听 [19](./19-对文档批注托付.md)  
> 目的：安装程序把本机跑成服务器；浏览器进工作台；架构师 / 产品经理靠账号和 ACL 区分。

## 1. 产品是什么

一句话：**给产品 / 设计 / 测试用的 Cursor / Claude Code。**

人看的是 Markdown 交付物（墨览）；主路径是圈选后托付 AI 改文档，不是先当编辑器手改。机器干的是 Claude Code 那套：读文档仓、改 Markdown。人不用面对终端、源码树、prompt、MCP。托付交互见 [19](./19-对文档批注托付.md)。

```text
想法 / 口述 / 粘贴草稿
        ↓ 建工程（仍可拷模板或导入）
      文档仓（墨览预览）
        ↓ 圈一块 + 说一句 → AI 改文档
      以后：skill / 读代码 / SR / 测试方案
```

墨览不是产品本身，是人机共用的纸面。VS Code 墨览扩展继续服务「已经在 IDE 里的人」，不当主产品。现行能力见 [16](./16-墨览现状.md)。

## 2. 两个角色（已拍板）

**同一套 Web，权限不同。** 不上 Tauri 工作台。

| 角色 | 能做什么 | 不能做什么 |
|------|----------|------------|
| **架构师** | 设运行根目录、从 `~/.claude.json` 批准代码目录、配 Claude / MCP / skills、管账号、建/删工程、写文档、开 Agent、解除编辑权 | — |
| **产品经理** | 自己建工程、编辑文档包、开 Agent、看进度 | 改配置、看密钥、批准代码目录、管用户、删工程 |

MCP / skills：**默认全开**（复用托管机 `~/.claude`）。架构师可在设置里关掉；产品经理看不到设置。

安装完成后第一个账号就是架构师。产品经理由架构师创建，只拿地址和登录方式。

界面写「产品经理」。代码角色值仍是 `designer`。

## 3. 纠正后的产品假设

| 原假设 | 现假设 |
|--------|--------|
| Docker / 云 / Tauri 桌面壳 | **安装程序 + 以服务器方式运行的本机程序** |
| 角色靠不同客户端区分 | **用户系统 + ACL**；界面都是浏览器 |
| 文档写进主仓 `.designweave/` | **运行根目录下每个子文件夹一个工程**；代码目录只读、与工程脱钩 |
| Agent 自带一套工具 | **复用托管机上的 Claude Code**；默认全开，架构师可关 |

## 4. 运行形态（已拍板）

```text
托管机（安装包打进去）
├── 本机服务器进程（开机可启动）
│     Web UI + API + Agent 调度
│     内置 Node
├── 用户 / ACL（架构师、产品经理）
└── 磁盘：workspaceRoot（可写）+ 已批准代码目录 × N（只读）

架构师 / 产品经理 ──浏览器──▶ http://主机:端口
```

- 需要 **安装程序**（先 macOS，再 Windows）：装完即服务，不必 `pnpm dev`。
- **不做 Electron / Tauri 工作台。**
- **不换 Deno/Bun。**
- 服务可听本机或局域网；**必须登录**；不对公网裸奔。
- 选运行根目录：架构师浏览**服务器本机路径**。代码目录只从 `~/.claude.json` 扫入再批准，不浏览磁盘补挂。
- Docker 只留开发者附录。

| 点 | 含义 |
|----|------|
| Claude / MCP | 只存在于 **托管机**；全员用架构师配好的能力包 |
| 长任务 | 活在后台 run / session 里；关浏览器不等于取消 |
| 写代码 | 默认关。Agent 只改文档工程文件夹 |
| 权限 | 同一 API，按角色拒绝 |

## 5. 与 Claude Code 的关系

DesignWeave **不是**另起一套 Agent 生态，而是在文档工作流上调用托管机已配置好的 Claude Code（Agent SDK）。

启动时扫描并复用 `~/.claude/settings.json`、`~/.claude.json`、工程 `.claude/`、MCP / plugins。**默认全开**，密钥只引用、不复制。只有架构师能改开关。代码目录如何批准、如何给 AI 用，见 [01](./01-Claude配置复用与工程绑定.md)、[18](./18-工程目录与标准PRD.md) §6。

## 6. 工程怎么绑

一个设计工程 = **运行根目录下的一个子文件夹**（可写，Git 管理）。代码目录是服务级已批准名单，**不挂在某个产品经理工程上**。AI 读文档后自己识别可能相关的仓。未批准任何代码目录时，允许只有文档；可行性不可用。

详见 [18](./18-工程目录与标准PRD.md)。

## 7. 明确不做（本阶段）

- Docker Compose 作为主安装路径
- Tauri / Electron 当工作台或「架构师专用壳」
- 产品经理改 MCP / 密钥 / 批准代码目录
- 默认改业务代码
- 多租户公网 SaaS
- 绕过企业 Claude Code、另建平行 MCP 市场
- 通用笔记库（wikilink / 图谱 / 日更）
