## 1. 产品一句话

给产品 / 设计 / 测试用的 Cursor / Claude Code。人改 Markdown（墨览），机器用本机 Claude Agent SDK 看代码、补文档。不是笔记库，不是第二个 Obsidian。

## 2. 已拍板（不要再选型）

| 项 | 结论 |
|----|------|
| 分发 | **安装程序 + 本机以服务器方式运行**（内置 Node）。全员用浏览器 |
| 不做 | Tauri / Electron 工作台；Docker 主路径；Deno/Bun 换栈 |
| 角色 | **同一套 Web**。架构师 vs 产品设计 = 账号 + ACL，不是两个客户端 |
| 用户 | Better Auth + `role` 字段。不要 Keycloak / Casbin / OpenFGA |
| 文档 | 每工程 **一个专有文档根（可写，Git 管理）** + **N 个代码根（只读）**。人写的和 AI 写的都能对比、回退 |
| 文档进浏览器 | 磁盘或 Git 一变，只读中的墨览/文件树要跟上，不是靠刷新。同一时刻只有一个写者（人改或 AI 跑）；点发送前所有人、所有文档不在编辑态。别人可进工程只读预览 |
| Agent | 继续 `@anthropic-ai/claude-agent-sdk`。借鉴 AgentScope 2.0 的 **session / 多用户形状**，不引入 Python 运行时 |
| Session | 连接 ≠ 任务。`POST` 立刻返回；`GET /sessions/{id}/stream?after=seq` 可重放 |
| MCP/skills | 托管机 `~/.claude` **默认全开**；仅架构师可关 |
| 对话 UI | AG-UI 事件子集；侧栏第一版自研；不上 CopilotKit |
| 墨览写回 | `GET/PUT /v1/files` + `If-Match` etag。编辑器不碰磁盘 |
| 语言 | 后台 TypeScript/Node；安装包带 Node |

第一用户 = 架构师。产品设计由架构师创建。管理接口无架构师角色则 403。

## 3. 第一刀（内部可日用）

验收（与 [11-4 P0](./11-设计稿-4-综合与待拍板.md) 对齐）：

> 产品经理打开已有工程 → 托付一次可行性调研（期间只能看、不能改）→ 写完后改一版 PRD → 能分清 AI 写的和我写的，并能回到其中任意一版；调研过程中已落下的章节当时就能在只读墨览里看见。别人可进同一工程只读预览，不能改。

开发仍可用 `pnpm` 起服务。安装包打磨不在本刀。

1. 本机服务器（现有 agent + web 演化）+ 登录与角色 ACL  
2. 扫 `~/.claude`，MCP 全开；仅架构师可关  
3. 架构师用目录树选文档根（必须初始化/使用主线版本库）+ 可选代码根；产品经理只进已有工程  
4. 三栏工作台：墨览打开文档，Cmd+S → PUT 写回（保存 ≠ 记入版本）  
5. 开 session，流与连接分离；Agent 只写文档根、只读代码根  
6. 同一时刻一个写者；点发送前所有人、所有文档不在编辑态且无未完成 AI；一人持有编辑权，别人只读预览  
7. 人点「记入版本」；AI 一轮成功自动记一版；只读时文件/文件树跟随磁盘  
8. 时间线 / 对比 / 打开旧版 / 恢复单篇 / 撤销最新 AI 版；信任条与失败人话  

暂不做：安装包打磨、产品设计邀请流、文档 diff 采纳、拆 SR、改业务代码、公网、实时协同、脏文档三选一、文档分支、远端推送。

切片顺序见 [12](./12-实现前决策.md)：登录 ACL → 文件+Git → 墨览宿主 → session 流 → 互斥与预览锁。
