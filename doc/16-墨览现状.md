## 它是什么

开源 Markdown 阅读 / 编辑器（Vditor IR，类 Typora）。打开默认预览，要点再编辑。同一套核心三端用：

| 端 | 位置 | 宿主 |
|----|------|------|
| Cursor / VS Code 扩展 | `apps/vscode-molan` | webview；商店扩展 `fengshihao.molan-markdown`，当前 0.1.16 |
| 浏览器工作室 | `tools/markdown-viewer` | 本地打开文件夹，Chrome / Edge 可写回 |
| Web 工作台 | `apps/web` 经 `MolanFrame` | **同页 inline 挂载**，保留 `reader-header`，不用 iframe |

共享包：`packages/molan-core`（编辑器 / CSS 真源）、`packages/molan-host`（壳与桥）、`packages/molan-protocol`（宿主协议）。三端用 sync 从 dist 取产物，不要再手改 `public/molan` 或 `media/`。

## 已经有的能力（扩展 0.1.16）

- 预览 / 编辑切换；未改动关闭不询问保存
- 公式、Mermaid、表格（选行列、增删行列）、任务列表、代码块
- 预览与编辑行首「+」插入块；查找；大纲
- 流程图：独立编辑对话框、预览/灯箱缩放、可进编辑
- 导出 PDF / PNG；四种纸面（宣纸、墨夜、终端、胭脂）；排版与正文字体记在本机
- 多语言；内置裁剪 Vditor，不依赖外网 CDN

## 工作台怎么用它

- 主题跟 `document.documentElement` 走，和壳体同一套纸面
- 文件名、保存态、编辑/预览放在墨览顶栏，工作台不要再写一遍
- 编辑器只碰字符串；写盘走 `GET/PUT /v1/files` + `If-Match`
