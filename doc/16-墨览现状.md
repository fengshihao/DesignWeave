# 墨览现状

> 2026-09-16 · 二期：真源迁至独立仓库。

## 它是什么

开源 Markdown 阅读 / 编辑器（Vditor IR，类 Typora）。打开默认预览，要点再编辑。

**真源仓库**：[fengshihao/molan](https://github.com/fengshihao/molan)（与 DesignWeave 并列 clone 到 `../molan`）。

| 端 | 位置（molan 仓） | 宿主 |
|----|------------------|------|
| Cursor / VS Code 扩展 | `apps/vscode-molan` | webview；商店 `fengshihao.molan-markdown` |
| 浏览器工作室 | `apps/studio` | 本地文件夹写回 |
| DesignWeave 工作台 | 本仓 `apps/web` 经 `MolanFrame` | 同页 inline；依赖 `@molan/host`（`file:../molan/...`） |

共享包（均在 molan）：`@molan/core`、`@molan/host`、`@molan/protocol`。

本仓 `pnpm predev` 会构建并列 molan 并把产物 sync 进 `apps/web/public/molan/`。

## 本机

```bash
# 同级目录
git clone https://github.com/fengshihao/molan.git
cd DesignWeave && pnpm install && pnpm dev

# 墨览独立开发
cd ../molan && ./molan help
```
