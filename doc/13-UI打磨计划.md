# UI：纸面占主

> 2026-08-22：单页全屏与发现方式以 [18](./18-工程目录与标准PRD.md) §7 为准。  
> 本文只留仍有效的空间原则，不再写多页首页、分步向导、产品经理不能新建。

## 谁在写，谁占主

同一时刻一个写者，所以同一时刻只有一块 UI 该大。

- 人在改：墨览铺满，托付收成底条（档位 + 一句输入）。
- AI 在跑：纸面只读跟上磁盘；托付层浮在预览上，可在收起 / 半幅 / 铺满之间切。
- 预览者：同一套浮层，没有发送 / 取消。

时间线、对比、撤销进「版本」抽屉，不进托付层。发送被拦时再出一句人话，不常驻说明书。

## 不要做

- 换字体栈、上仪表盘风
- 把托付层做成整页 ChatGPT
- 给产品经理浏览磁盘或批准代码目录
- 浏览器本地目录 API 当工作台保存
- 实时双光标、专业 diff
