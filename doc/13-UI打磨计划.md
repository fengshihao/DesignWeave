# UI 打磨计划

> 2026-08-16 · P0 功能已进主干之后，把「能用」收成「像工作台」。  
> 产品规则仍听 [11-4](./11-设计稿-4-综合与待拍板.md) / [12](./12-实现前决策.md)，本文件只打磨界面与选择器，不重开选型。  
> 人若改口：先改本文，再动代码。

当前 `apps/web` 仍是探针壳套上了真功能：表单堆字段、右侧 AI 挤成一条窄栏、选目录是一列按钮。02 早就写过「不像本机工作台」——功能齐了，这句话还成立。

---

## 已拍：这一轮怎么打磨

| # | 问题 | 决定 |
|---|------|------|
| 1 | 选托管机目录用哪个开源文件管理器？ | **不引入全功能文件管理器。** 自研「托管机目录选择器」对话框，交互学资源管理器。数据仍走 `/v1/fs/browse`。 |
| 2 | 选择器要不要新建文件夹？ | **要。** 架构师在当前目录下建子目录，再建工程。只建目录，不删、不改名、不上传。 |
| 3 | 人改文档和 AI 跑任务怎么分主次？ | **谁在写，谁占主。** 两者互斥，界面不要永远对半劈。AI **不固定钉在右边**。 |
| 4 | AI 对话放哪、怎么调大小？ | **浮在只读预览上的托付层**，一点按钮在「收起 / 半幅 / 几乎铺满」之间切换，边缘可拖。人在改时自动收成底条。 |
| 5 | 要不要重做视觉系统？ | **不要换皮。** 沿用现有纸面色（宣纸 / 墨绿）。把内联样式收进组件，去掉后台表单感。 |

不引入 SVAR / Cubone 一类完整 File Manager 的原因：它们默认带删除、上传、剪贴、预览任意文件。对着**托管机整盘**太危险；主题（Willow 等）也和墨览纸面对不上。浏览器 File System Access 仍然禁止（12 已拍）——选的是服务器磁盘，不是操作者自己电脑。

## 现在哪里糙（按页面）

### 1. 新建工程 · 选目录（你点名的）

现状：一个输入框 +「浏览」后出现最高 180px 的按钮列表，只能一级级点，**不能新建目录**，不能看文件（只好猜这是不是对的文件夹），没有面包屑。

目标：点「选择文档目录」弹出对话框，像简单文件管理器：

```text
┌ 选择文档目录 ─────────────────────────────────┐
│  家目录 / 文档 / DesignWeave          [上一级] │
│  ┌──────────────────────────────────────────┐ │
│  │ 📁 设置页夜间模式                         │ │
│  │ 📁 负一屏                                 │ │
│  │ 📄 README.md          （可见，不能选文件） │ │
│  └──────────────────────────────────────────┘ │
│  [+ 新建文件夹]     当前：…/DesignWeave         │
│                         [取消]  [使用此目录]   │
└──────────────────────────────────────────────┘
```

- 面包屑可回跳任意一级；双击文件夹进入；单击选中
- 文件夹和文件都列出（文件灰着，避免选到代码仓还看不出来）
- 「新建文件夹」：在当前路径 `mkdir`，立刻出现在列表里
- 地址栏可粘贴/回车跳转（架构师本来就会手打路径）
- 同一组件给「文档目录」和「手选代码仓路径」共用
- 新建工程向导改成短步骤：名称 → 选文档目录 → 勾选代码仓 → 可选远端栏（P0 空着也要有）→ 可选导入。不要一页堆八个 field

后端补：`POST /v1/fs/mkdir`（仅架构师）。禁止 `..`，只在已能 browse 的树上建一层。不提供删除/重命名。

### 2. 托付层 · AI（你点名的）

现状：右栏锁死 **340px**；进度区最高 240px；档位、信任条、日志、输入、**整条时间线**全塞右边。人在改文档时也被这条窄栏永远切走一块纸面。

**空间原则（比「永远三栏」更准）：** 同一时刻只有一个写者，所以同一时刻只有一块 UI 该大。11-2 的固定右栏作废，房子仍是「纸面是主、对话是手段」。

```text
人在改（编辑台）
┌ 文件树 ┬ 墨览铺满 ─────────────────────────────┐
│        │                                      │
│        │                                      │
│        │                                      │
└────────┴──────────────┬ 共创 · 说下一步… [展开] ┘
                        └ 底条：档位 + 一句输入 + 发送

AI 在跑 / 人点了展开
┌ 文件树 ┬ 墨览只读预览（磁盘跟上）──────────────┐
│        │  ┌ 托付层（浮在预览上）────────── [半幅▾] ┐
│        │  │ 可行性 · 只读了设置App · 未改代码     │
│        │  │ 正在写 调研.md …          [取消本轮] │
│        │  └────────────────────────────────────┘
└────────┴──────────────────────────────────────┘
```

三档尺寸，一点按钮循环或下拉，记住这个工程上次用的：

| 档 | 什么时候 | 托付层 |
|----|----------|--------|
| 收起 | 人在改；或只想看纸面跟上 | 底条：档位、信任一句、输入/「进行中」、展开键。顶栏红点仍在 |
| 半幅 | 空闲要写托付；进行中要看进度又要瞥见文档 | 浮在预览右下或下半，约纸面 40～50% 宽，边缘可拖 |
| 几乎铺满 | 只关心这一轮在说什么 | 盖住预览大部分，仍留一条纸面边，避免变成独立 Chat 页 |

自动切换（可手改，手改优先）：

- 点墨览「编辑」→ 收到底条（人占主）
- 点发送且过了关卡 → 升到半幅（AI 占主）；人可再点铺满或收回看纸面
- 一轮结束 → 留在半幅，给出「对比 / 撤销 / 回到纸面」
- 预览者：同一套浮层，没有发送/取消；默认半幅，方便看别人的进度

仍要：

- **时间线、对比、撤销**在顶栏「版本」抽屉，不进托付层
- 信任条钉在托付层顶，一行说完，不跟消息滚走
- 对话按轮次成块（托付、中文进度、写了哪篇、失败人话），不要裸 `<p>`
- 半幅以上时输入至少 3 行；取消固定在层底
- 发送被拦：弹出说明，里面有「保存一版」（只记版+退出编辑，**不**发出那句）

不做：满屏乱拖的小窗、双栏同时可打字、把纸面缩成缩略图只剩聊天。

### 3. 工作台其余（一起收）

| 位置 | 现在 | 打磨 |
|------|------|------|
| 左栏 | 扁平路径列表；导入 textarea 常驻占一半 | 真树（`import/` 可折）。导入改成树底一个按钮，弹出粘贴/上传。可收 |

## 不做（避免打磨变成重做产品）

- 不换主题、不换字体栈、不上 Inter / 紫渐变仪表盘
- 不把托付层做成整页 ChatGPT，也不做可满屏乱拖的小窗
- 不给产品经理选文件夹、新建工程
- 不接浏览器本地目录 API
- 选择器不提供删除、重命名、移动、上传到任意磁盘
- 不做实时双光标、专业 diff、安装包视觉
- 不在这一轮改 Agent 协议或 Git 规则

## 实现顺序

每一刀单独可看，不要和功能重构搅在一起。

1. **托管机目录选择器**  
   对话框 + 面包屑 + 列表 + 新建文件夹 + `POST /v1/fs/mkdir`。新建工程、手填代码仓都用它。

2. **新建工程向导收短**  
   用选择器换掉按钮列表；补上远端空栏；字段分步。

3. **工作台骨架**  
   去掉固定右栏。纸面铺满；托付层三档（收起 / 半幅 / 铺满）+ 可拖；随人 XOR AI 自动切换；时间线进抽屉；发送关卡弹出「保存一版」。

4. **托付层对话流**  
   按轮次排进度/写文件/失败；半幅以上输入加高；预览者只读同一层。

5. **首页与附属页收形**  
   继续上次大卡片、工程状态、用户页复制块、设置页大判断。

6. **左栏树与导入**  
   真树 + 导入进弹层。可与 3 并行，但不要挡选择器和右栏。

## 怎么算打磨完

架构师新建工程时：能像文件管理器一样走进家目录、看见文件以免选错、当场建一个新文件夹、点「使用此目录」。

产品经理打开工程改文档时：纸面铺满，AI 只是底条，一点能展开。托付之后浮层盖在只读预览上，仍能拖小去看磁盘跟上的章节。时间线从顶栏打开。发送被拦时，提示里的「保存一版」只记版、不把那句话发出去。
